📄 __main__.ino — Entry Point

This file is intentionally minimal. It handles only hardware instantiation and the Arduino setup()/loop() lifecycle.

What It Does

#StepDetail
1IncludesPulls in Machine.h and all required libraries
2Keypad SetupDefines 4×4 key matrix, rows D6–D9, cols D10–D13
3LCD SetupI2C address 0x27, 16 columns × 2 rows
4Machine ObjectPasses keypad and LCD by reference
5setup()Serial at 115200 baud → machine.Initialize()
6loop()keypadPress() → runState() every iteration
Design Note
All logic lives inside the Machine class. This keeps __main__.ino as a thin wiring layer — no business logic, no state management.

Initialize() Line 50–105

Boot sequence executed once in setup():

Power ON ├─ Pin modes (buzzer = OUTPUT, POT = INPUT) ├─ LCD init + backlight + "System starting!" ├─ ZMPT101B sensitivity set (both sensors) ├─ ACS712 sensitivity + calibrate() (auto-zero, no load) ├─ Load tolerance from EEPROM byte 0 ├─ Load target from EEPROM byte 1 │ └─ If valid (0–250) → set REG_ACTIVE automatically ├─ homeToZero() → servo spins CCW until POT ≤ 5 ├─ 1 second delay └─ Show HOME screen
⚠️ Important
currentSensor.calibrate() must run with no load connected to get an accurate zero-point reading.

homeToZero() Line 153–196

Moves servo to the physical 0V position on boot using POT feedback.

Read POT (A2) ├─ POT ≤ 5 → "Already at 0V" → skip └─ POT > 5 → LCD: "Homing to 0V..." ├─ Spin CCW at 1300µs (slow) ├─ Monitor POT continuously ├─ POT ≤ 5 → STOP → "Homed to 0V" ✅ └─ 15s timeout → STOP → "Home failed!" ⚠️
Note
This is the only blocking function besides readCurrent(). Runs once during boot.

Confirmation Window

Vout must stay continuously outside tolerance for 3 seconds before the servo acts. If Vout returns to tolerance at any point, the timer resets. This prevents hunting from noise spikes.

Alarms & Recovery Line 288–338

checkAlarms()

Detects stalled conditions — servo pulsing but Vout not changing.

ConditionAlarmMeaning
pulseDirection == +1 & stallREG_UNDER_VOLTAGEVariac maxed out, Vin too low
pulseDirection == -1 & stallREG_OVER_VOLTAGEVariac at minimum, Vin too high

Stall = Vout unchanged for STALL_TIMEOUT (3s) while servo is active.

checkAlarmRecovery()

Under Voltage: maxAchievable = Vin × (250/220). If ≥ target → recovered.

Over Voltage: If currentVout ≤ target + tolerance → recovered.

Recovery is automatic — no user intervention needed.
